# 自有域名部署指南（去 WorkBuddy 域名）

## 背景

当前线上链接 `https://llmshicao.app.workbuddy.host/` 的根域名 `*.app.workbuddy.host` 由托管平台固定分配，**无法在平台内改成自定义域名**。若要在简历/面试中呈现一个看不出托管平台痕迹的链接，需要将项目部署到自有服务器并绑定自有域名。

项目为**零依赖纯 Python 标准库**实现，`python server.py` 即可启动，可部署到任意 Linux 服务器。

---

## 方案 A：Docker 部署（推荐）

```bash
# 1. 构建镜像（在项目根目录 enterprise-platform-api/ 下）
docker build -t llm-platform .

# 2. 运行容器（映射 8000 端口）
docker run -d --name llm-platform -p 8000:8000 --restart=always llm-platform

# 3. 验证
curl http://127.0.0.1:8000/api/health
```

## 方案 B：裸机部署

```bash
# 1. 安装 Python 3.12+（无需任何 pip 依赖）
# 2. 上传项目目录，直接启动
cd enterprise-platform-api
PORT=8000 nohup python3 server.py > app.log 2>&1 &

# 3. 验证
curl http://127.0.0.1:8000/api/health
```

## 方案 C：systemd 守护（生产推荐）

```ini
# /etc/systemd/system/llm-platform.service
[Unit]
Description=Enterprise LLM Platform
After=network.target

[Service]
WorkingDirectory=/opt/llm-platform/enterprise-platform-api
Environment=PORT=8000
ExecStart=/usr/bin/python3 server.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now llm-platform
```

## 绑定自有域名 + HTTPS

1. **准备域名**：在阿里云/腾讯云购买域名，完成 ICP 备案（中国大陆服务器需备案）；
2. **DNS 解析**：添加 A 记录，将域名指向服务器公网 IP；
3. **Nginx 反向代理**：将 `deploy/nginx.conf` 中的 `your-domain.com` 替换为你的域名，放入 `/etc/nginx/conf.d/`；
4. **HTTPS 证书**（可选但推荐，简历链接更专业）：
   ```bash
   # 使用 certbot 自动申请免费 SSL 证书
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com
   ```

完成后，即可用 `https://你的域名/` 访问，链接不再暴露托管平台信息。

---

## 安全提示

- 平台自带鉴权/审计/合规治理模块，但线上公网部署建议在 Nginx 层再加一层访问控制（如 Basic Auth 或 IP 白名单）；
- 前端 API Key 仅存浏览器 localStorage、不落服务器，但仍建议配置模型服务端的调用限额。
